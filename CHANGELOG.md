# История изменений

## 0.1.0 — исходники размещены на GitHub 2026-10-07

### Возможности

- Показатели контекста и рабочий ориентир владельца без автоматического перехода по проценту.
- `context_handoff`: обновление текущего контекста, отдельная сессия с разрешением и уточнение названия.
- Снимки HANDOFF, сохранённые границы и связи сессий; продолжение текущей моделью без отдельного суммаризатора.
- Панель `/continuity`, переключатель до первого сообщения и история этапов.
- Отключение штатного автоматического сокращения и удаления старых результатов инструментов в экземпляре OpenCode.

### Подготовка проекта — 2026-10-07

- Инструкция модели находится внутри самостоятельного локального репозитория.
- README дополнен происхождением проекта, установкой обеих частей, ограничениями, отключением и восстановлением.
- Добавлены руководство разработки, карта состояния проверок интерфейса и явный состав локального архива.
- Проверки используют OpenCode из PATH или `OPENCODE_BIN`; ручная панель не зависит от внешнего файла конфигурации.
- Подготовлены проверка серверной загрузки из архива и workflow без публикации.
- Основной README — на английском, русская версия — `README.ru.md`; тексты плагина и его инструкции модели переведены на английский по просьбе владельца.
- В обоих README выделена постепенная проверка изменений HANDOFF вместе с ответами модели в процессе работы — ключевая часть замысла, уточнённая владельцем.
- README сокращены: список проблем длинных сессий с GPT Astra/GPT-6.1 Sol, конкретная помощь плагина и качественная оценка по опыту создателя; установка свёрнута.
- Раздельно объяснены продолжение работы в том же чате после сокращения контекста и новый чат для другой темы. Возвращено связное описание главных беспокойств создателя.
- После одобрения русского текста добавлена заключительная заметка о рабочем эксперименте, адаптации подхода и исследовании сборки входа, кеша, памяти и управления агентом.
- В инструкции плагина уточнено ведение отдельного состояния каждого проекта, создание HANDOFF при отсутствии, обновление по ходу работы, результаты проверок и встреченные трудности. README объясняет, что добавляется в запрос и какой файл можно настроить.

Исходники открыто размещены в [roboroddom/opencode-smart-context](https://github.com/roboroddom/opencode-smart-context); по поручению владельца собственный код лицензирован под 0BSD, сторонний MIT-фрагмент сохраняет NOTICE. GitHub Actions прошёл успешно. Отдельный тег/релиз и npm-публикация не выполнялись.
