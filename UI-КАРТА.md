# Карта интерфейса помощника контекста

## Панель и индикаторы `/continuity`

- Код: `tui.tsx`, реальные слоты и диалоги OpenCode TUI.
- Демонстрация: `bun run test:ui` — отдельная временная конфигурация настоящего OpenCode. Отдельной страницы всех состояний сейчас нет.
- Входы и состояния: начальный экран без сессии; помощник включён/выключен; сессия до первого измерения; измеренный расход; обновлённая граница со старыми показателями; этапы и снимки; связанные сессии; ошибка перехода; ручная просьба основной модели обновить контекст.
- Прежние локальные функциональные проверки: начальный индикатор, меню и выключение до первого сообщения в OpenCode V1 1.18.34. Это запись проверки агентом, не одобрение владельца.
- **Конкретное одобрение владельца:** в текущей передаче не зафиксировано. Не считать интерфейс или все перечисленные состояния одобренными.
- Проверенная редакция: прежняя локальная версия `0.1.0`, без коммита; точная привязка к хешу редакции в старой проверке отсутствует. По прямой просьбе владельца 2026-10-07 тексты `tui.tsx` переведены на английский, числовое форматирование — `en-US`; структура и действия сохранены. Старые проверки не подтверждают отображение новых текстов.
- Открыто: демонстрация всех состояний и проверка владельцем; работа интерфейса из архива на чистой установке; другие ОС, Web/Desktop.

В этой задаче изменены только язык и форматирование текстов интерфейса. Отображение новых строк владелец ещё не проверял. Перед будущим изменением структуры оформить отдельную демонстрацию настоящего компонента по правилам владельца и записать конкретные проверенные варианты.
